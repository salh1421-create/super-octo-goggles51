# منظومة تقارير دعم التميز المدرسي 🎓

## نظرة عامة
منظومة ويب متقدمة لإدارة وتقديم التقارير المدرسية بقطاع العوالي، مصممة لفريق التعليم التنفيذي في المدينة المنورة.

---

## ✨ الميزات الرئيسية

### 🔐 نظام المصادقة
- دخول آمن لأعضاء الفريق التنفيذي
- دعم دوري الرئيس والأعضاء
- حساب شخصي لكل عضو

### 📋 إنشاء التقارير
- **نموذج شامل** يتضمن:
  - بيانات الزيارة والمدرسة
  - ملخص التقويم المدرسي
  - تقييم الممارسات الإشرافية
  - تقييم الخدمات المقدمة
  - الجدارات الوظيفية
  - التعليقات والملاحظات

### 📊 لوحة الإحصائيات (لرئيس الفريق)
- إحصائيات شاملة للمدارس والتقارير
- رسوم بيانية متقدمة مع Chart.js
- جداول ملخصة لأداء كل عضو
- فلاتر ديناميكية

### 📱 إدارة التقارير
- قائمة التقارير المحفوظة مع فلاتر متقدمة
- إجراءات سريعة: عرض وتعديل
- إحصائيات شخصية لكل عضو

### 🖨️ الطباعة والتصدير
- طباعة فورية من المتصفح
- تصدير PDF معتمد
- نماذج مطابقة 100% للمتطلبات الرسمية

---

## 🚀 البدء السريع

### المتطلبات
- متصفح حديث (Chrome, Firefox, Safari, Edge)
- اتصال إنترنت

### طريقة الاستخدام

1. **الدخول إلى المنظومة**
   - المستخدم: اختر من القائمة
   - كلمة المرور: 123456

2. **إنشاء تقرير**
   - اضغط "إنشاء تقرير جديد"
   - اختر المدرسة (التعبئة التلقائية)
   - أكمل الحقول المطلوبة
   - احفظ واعتمد التقرير

3. **عرض الإحصائيات** (رئيس الفريق فقط)
   - اضغط "لوحة الإحصاءات العامة"
   - استخدم الفلاتر
   - صدّر كـ PDF
