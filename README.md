# منظومة تقارير دعم التميز المدرسي - قطاع العوالي

نظام ويب سحابي وتطبيق متكامل لإدارة واستكمال تقارير التغذية الراجعة لمقدمي خدمات دعم التميز المدرسي وإصدار مستندات رسمية (PDF) مطابقة للمواصفات الوزارية.

## المميزات
- تسجيل دخول آمن لكل عضو من أعضاء الفريق التنفيذي بكلمة مرور.
- إدراج التوقيع الإلكتروني الرسمي تلقائياً لكل تقرير معتمد.
- دعم كامل لعمليات (إضافة، تعديل، حذف، استعراض).
- إخراج رسمي متوافق مع الكليشة الوزارية وشعار وزارة التعليم.
- صيغة أرقام قياسية موحدة (123).
- جاهز للنشر المباشر على GitHub Pages أو Vercel أو Netlify.

## طريقة التشغيل على GitHub Pages
1. قم بإنشاء مستودع جديد على GitHub (مثلاً: `excellence-feedback-system`).
2. ارفع ملف `index.html` وملف `README.md`.
3. من إعدادات المستودع (Settings) -> Pages -> اختر فرع `main` واضغط `Save`.
4. سيصبح موقعك متاحاً ويعمل سحابياً بشكل فوري!
